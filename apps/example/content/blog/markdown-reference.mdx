## Lists

1. Ordered lists count up
2. They can nest
   - Unordered inside ordered
   - Still readable
3. And continue afterwards

- Unordered lists use the muted marker color
- Long items wrap without breaking the indent, which matters once a sentence runs over two lines on a phone.

## Code

TypeScript:

```ts
type Post = { slug: string; date: string };

export function newest(posts: Post[]): Post | undefined {
  return [...posts].sort((a, b) => b.date.localeCompare(a.date))[0];
}
```

Python:

```python
def reading_time(words: int, wpm: int = 220) -> int:
    return max(1, round(words / wpm))
```
